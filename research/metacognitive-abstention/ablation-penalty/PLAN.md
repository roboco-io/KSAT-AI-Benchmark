# 후속 인과 실험 계획서: 오답 감점제(Penalty-Incentive)가 LLM의 기권 행동을 바꾸는가?

2026-11-25 · 격리 통제 실험 (기존 `results/` 및 대시보드와 완전 분리)

## 1. 연구 질문 및 가설

선행 관찰 연구([REPORT.md](../REPORT.md))에서 LLM은 과학탐구(비도표 53.7%, 도표 56.1%)에서는 오답을 기권으로 잘 걸러냈으나, 비도표 사회탐구에서는 오답 포착률(ECR)이 3.9%로 붕괴했고, `deepseek-v4.1-flash`처럼 오답 208건·기권 0건인 무기권 모델군이 관찰되었다.

그러나 관찰 데이터만으로는 두 가지 대립 가설을 구분할 수 없다:
* **대립 가설 A (인센티브·임계값 가설):** 모델은 내부적으로 불확실성을 알고 있지만, 감점이 없는 기본 시험(C0)에서는 5지선다 추측의 기댓값(+0.2)이 기권(0)보다 높으므로 합리적으로 추측을 선택했다. **기권 0점·오답 감점(-1점, -3점)** 규칙을 명시하면 기권률이 급등하고 비도표 사회탐구와 무기권 모델에서도 메타인지가 깨어날 것이다.
* **대립 가설 B (구조적 사각지대 / 기권 억제 가설):** 감점을 주더라도 (1) 비도표 사회탐구에서는 내부 검증 신호 자체가 없어 여전히 과신 오답이 지배하거나, (2) 감점이 정밀한 오답 포착 대신 기존에 맞히던 문항까지 포기하는 무차별 과잉 기권(blanket cowardice)을 유발하거나, (3) 사후학습으로 기권이 억제된 모델은 감점에도 반응하지 못한다.

### 2.3 통제 조건 (Within-Subject Paired Design)
동일한 200 DPI 무손실 WebP 시험지 이미지, 동일한 JSON 출력 스키마, 동일한 외부 검색·도구 완전 차단(Closed-Book) 환경을 유지하고 **채점 규칙 문구만** 조작한다.

* **C0 (`baseline`):** 기존 동결 2027 4교시 실행 답안 재사용 (추가 호출 0회). 기권 허용, 감점 미명시.
* **C1 (`penalty_1`, λ = 1):** 정답 `+1점`, 기권 `0점`, 오답 `-1점` 명시 (합리적 응답 임계값: 확신도 > 50%).
* **C2 (`penalty_3`, λ = 3):** 정답 `+1점`, 기권 `0점`, 오답 `-3점` 명시 (합리적 응답 임계값: 확신도 > 75%).

총 신규 호출: **3모델 × 2조건 × 4그룹 = 24회 그룹 요청** (동시성 2, API 환산 상한 run당 $2.0).

## 3. 핵심 인과 평가지표

1. **3×3 문항별 행동 전이 행렬 (C0 → C1, C0 → C2):**
   * **유익한 기권 전환 (`Wrong → Abstained`):** 기존 오답을 감점 조건에서 기권으로 회피한 비율 $p_{\text{WA}}$
   * **해로운 과잉 기권 (`Correct → Abstained`):** 기존 정답을 감점 때문에 포기한 비율 $p_{\text{CA}}$
   * **기권 선택성 비율 (Selectivity Ratio):** $p_{\text{WA}} / p_{\text{CA}}$ 및 Fisher 정확 검정 (감점이 실제로 '모르는 문제'만 골라 기권시키는지, 무차별 위축인지 판별)
2. **영역별 감점 탄력성 (Domain Elasticity):** `비도표 사탐(40문항)` vs `도표 사탐(20문항)` vs `과탐(20문항)`에서 C0 → C1 → C2의 ECR 변화 및 Fisher 검정.
3. **실제 순효용 변화 ($\Delta U_\lambda$):** 감점 $\lambda \in \{1, 3\}$ 환경에서 모델이 감점 프롬프트에 적응했을 때의 실제 효용 $U_\lambda(\text{adapted})$ vs 기존 C0 답안을 동일 $\lambda$로 채점한 효용 $U_\lambda(\text{baseline})$.
4. **기권 해설 메커니즘 변화:** C1/C2에서 새로 발생한 기권이 기존과 마찬가지로 연역·시각 실패에 머무는지, 아니면 순수 사실·기억 부재(`factual_knowledge_gap`) 인식이 실제로 깨어나는지 분석.
