# 문제지 전사본 (형식 버전 1)

이 디렉토리는 수능 문제지 PDF를 쪽 단위로 옮겨 적은 텍스트 전사본을 보관한다. 전사본은 이미지 입력을 받지 않는 모델을 평가할 때 문제지 이미지 대신 전송하는 입력이다. 이미지 입력 모델의 평가에는 사용하지 않는다.

영어 문제지 5-8쪽은 PDF의 텍스트 층에서 직접 추출했으므로 줄바꿈이 인쇄본의 행과 같다. 그 밖의 쪽은 문단 단위로 이어 적었다. 두 방식 모두 글자는 PDF 텍스트 층과 기계 대조했고, 텍스트 층에 없는 수식·그림·밑줄·옛한글은 원본 이미지를 두 번째로 독립 판독해 확인했다.

전사본은 한 번 작성한 뒤 고정한다. `exams/transcripts/<학년도>/manifest.json`이 각 쪽 파일의 SHA-256을 기록하고, 실행기는 요청을 보내기 전에 이 해시를 검사한다. 전사본을 수정하면 해시가 달라지므로, 이미 시작한 실행은 이어서 진행할 수 없고 새 실행으로 다시 시작해야 한다.

## 파일 배치

원본 PDF의 한 쪽이 파일 하나에 대응한다.

| 원본 | 전사 파일 |
|---|---|
| 국어영역 문제지 N쪽 | `<학년도>/korean/page-NN.md` |
| 수학영역 문제지 N쪽 | `<학년도>/math/page-NN.md` |
| 영어영역 문제지 N쪽 | `<학년도>/english/page-NN.md` |
| 영어영역 듣기평가 대본 N쪽 | `<학년도>/listening/page-NN.md` |
| 2027학년도 4교시 과목 문제지 N쪽 (한국사는 홀수형 1-4쪽) | `2027-period4/<과목 코드>/page-NN.md` |

실행기는 문제 그룹에 속한 쪽 파일을 쪽 번호 순서로 이어 붙여 모델에 보낸다.

## 전사 규칙

전사자는 문제지에 인쇄된 내용만 옮긴다. 문제를 풀지 않고, 정답표를 보지 않으며, 풀이에 도움이 되는 해석이나 힌트를 덧붙이지 않는다. 원문의 오탈자로 보이는 부분도 고치지 않는다. 판독할 수 없는 부분은 추측하지 않고 `[판독 불가]`로 적는다.

읽는 순서는 왼쪽 단의 위에서 아래, 그다음 오른쪽 단의 위에서 아래다. 쪽 번호, 영역 표제, "홀수형" 표기, 저작권 문구, 확인 사항 같은 반복 인쇄 요소는 옮기지 않는다. 선택과목 표제, "5지선다형"·"단답형" 구분, "[1~3] 다음 글을 읽고 물음에 답하시오." 같은 지시문은 옮긴다.

| 원문 요소 | 전사 표기 |
|---|---|
| 문항 번호, 배점 | `11.` 과 `[4점]` 을 원문 그대로 |
| 선택지 | `①`-`⑤` 기호를 그대로 쓰고 선택지마다 한 줄 |
| 밑줄 | `<u>않은</u>` |
| 굵은 글씨 | `**글자**` |
| 기울임 글씨 | `*글자*` |
| 아래첨자·위첨자(수식이 아닌 본문) | `T<sub>0</sub>`, `<sup>` |
| 네모 테두리로 강조한 용어 | `[용어]` |
| 원문자·기호 | `㉠`, `ⓐ`, `(가)` 를 그대로 |
| 여러 줄을 묶는 괄호 표시 [A] | `【A 시작】` 과 `【A 끝】` 사이에 해당 범위 |
| <보기> 상자 | `<보기>` 한 줄 뒤에 인용문(`> `) |
| 그 밖의 상자 글 | 인용문(`> `) |
| 빈칸 | `__________` |
| 수식 | LaTeX. 문장 안은 `$...$`, 독립 수식은 `$$...$$` |
| 표 | Markdown 표 |
| 각주 | `*` 표기를 그대로 |

## 그림·그래프·도표

그림은 다음 블록 안에 글로 기술한다.

```
[그림 시작]
(기술)
[그림 끝]
```

기술에는 그림에 실제로 그려진 것만 적는다. 그림의 종류, 인쇄된 모든 라벨과 수치, 좌표축과 눈금 표시, 점·선·곡선·영역의 이름, 표시된 길이와 각, 음영, 그리고 그려진 대로의 위치 관계(어느 점이 어느 선분 위에 있는지, 무엇이 무엇의 왼쪽·위에 있는지)가 대상이다. 그림에서 계산하거나 추론해야 알 수 있는 값은 적지 않는다. 도표와 안내문 형태의 그림은 그 안의 글자와 수치를 모두 옮긴다.

그림 블록이 문항의 발문이나 선택지에 있거나, 그림이 있는 지문에 딸린 문항은 `manifest.json`의 `figure_dependent` 목록에 올린다. 이 목록은 결과를 낼 때 "그림 의존 문항을 제외한 점수"를 따로 계산하는 데 쓴다. 그림을 글로 옮기면 모델이 원본 그림을 직접 보는 것과 조건이 달라지기 때문이다.
