# 공통 오답 연구 계획과 실행 결정

요청: 연구 주제 ① ‘모델 간 공통 오답과 상호보완성’을 기존 프로젝트 자료로 진행한다.

범위: 2025·2026학년도 고정 답안, 고유 문항 기준, 공식 정답으로 재채점. 새 모델 호출·기존 답안 수정·웹 게시·커밋은 하지 않는다.

질문: 고득점 모델들의 오답은 겹치는가? 같은 문항에서 같은 선택지를 틀리는가? 최빈값 투표·엄격한 과반수·oracle 상한은 어떻게 다른가? 전년도에 고른 조합은 다음 학년도에도 개선되는가?

Ruling: 연구자 수준 한국어 보고서를 작성한다. 선택적 선호 질문에 답이 없는 동안 데이터 확인을 진행했고, 제안한 기본값을 사용한다.

Ruling: A=저장 답안·공식 정답 메타데이터, B=재현 가능한 계산, C=선행연구·해석. 이는 자료의 역할 구분이며 B가 A보다 독립적인 증거라는 뜻은 아니다. 공식 정답 원본을 새로 검수한 연구는 아니다.

Ruling: 실행은 AI가 진행한다. 사용자의 ‘1로 연구를 진행’ 지시로 로컬 분석과 산출물 작성을 승인받았다. 추가 승인 절차를 만들지 않는다.

Ruling: 공식 채점을 주 분석으로 사용한다. 2026 영어 37번의 운영상 복수정답 인정은 별도 민감도 분석으로 둔다.

Ruling: 완료된 이미지 입력 모델을 주 분석으로 사용한다. 미완료 모델과 텍스트 입력 모델은 별도로 포함해 민감도를 확인한다. 공통 9개 모델 패널과 동일 연도 95% 이상 고득점 패널도 산출한다. 고득점 패널은 사후 기술 분석이다.

Ruling: 지문 ID가 없어 과목 내 쪽 번호 군집 bootstrap과 실행 묶음 군집 민감도를 계산한다. 둘 모두 실제 지문 군집을 대체하지 못한다. 특히 영어 실행 묶음이 하나이므로 해당 구간을 통계적 유의성의 근거로 쓰지 않는다.

Ruling: 모델 조합 선택은 코드에서 2025학년도만 사용하고, 2026학년도에 같은 조합을 적용한다. 이미 두 연도를 확인한 사후 연구이므로 사전등록·독립 전향 검증으로 주장하지 않는다.

근거 검색: 공식 논문 원문 페이지에서 오류 상관과 모델 앙상블의 선행연구를 확인한다. 저장 자료에서 원답·기권·오류·채점 보정·입력 방식·완료 상태를 확인한다. 읽기 전용 방법론 검토를 연구 에이전트에 위임했다.

산출물: `research/common-errors/`의 고정 입력, 해시, 표준 라이브러리 분석기, CSV·JSON, 정적 그림, 한국어 보고서와 근거 원장. 원장으로 findings/sources/contradictions를 생성한다.

검증: 공식·보정 채점의 저장 집계 대조, 투표·동률·기권·오류의 단위 검증, 독립 재계산, 스냅샷 무결성, 동일 실행 출력 해시 비교. 제품 코드를 바꾸지 않으므로 제품 전체 테스트 대신 해당 분석을 직접 검증한다.

외부 논문 파일은 내려받지 않고 원문 페이지 링크만 기록한다.
