# 공통 오답 연구 웹 게시

사용자 요청: 기존 연구 보고서를 웹에 게시하고 대시보드 연구 섹션에서 소개한다. 기존 GitHub Pages 배포 권한을 포함한 요청으로 진행한다.

Ruling: 기존 Next.js 정적 내보내기와 roboco.io의 GitHub Pages를 유지한다. 별도 Sites 호스팅은 만들지 않는다.

Ruling: 작고 연결된 정적 콘텐츠 추가이므로 한 흐름으로 구현한다. 대시보드의 학년도 선택 아래에 소개와 공식 정답 기준 결과 표를 놓고 `/research/common-errors.html`에 보고서 전체를 게시한다.

Ruling: 기존 남색(#172b4d)·인디고(#293d8e)·청록(#087568)·배경(#edf2f8)·흰 표면과 시스템 한글 글꼴을 유지한다. 연구 요약 표를 핵심 시각 요소로 사용하고 본문은 좁은 읽기 폭과 목차로 구성한다. 기존 자동 다크 테마 변수를 따른다.

Ruling: 동결된 원장에서 본문을 표시하고, 동결된 분석 JSON에서 요약 표를 생성한다. public 다운로드 자료는 prebuild에서 복사한다. 실제 모델 호출·기존 답안 변경·새 연구 계산은 없다.

Ruling: 기존 사용자 수정인 ComparisonDashboard.tsx의 점수 설명과 구형 수학 YAML 변경은 커밋에 포함하지 않는다.

검증: 보고서·입력 바이트 보존, 공식 완료 이미지 패널의 요약 값, 정적 HTML·앵커·연구 다운로드 경로를 Node 테스트로 검사했다. Next.js 빌드가 타입 검사를 포함해 통과했다. 기존 benchmark 오프라인 테스트 116개 통과. Chrome에서 데스크톱과 390×844 반응형 보고서·대시보드 연구 섹션을 확인했다. 별도 읽기 전용 최종 검토 결과 APPROVED.

배포: 연구 근거와 웹 게시 변경을 논리적인 두 커밋으로 나누고 origin/main에 push한다. Actions 완료 및 실제 공개 URL·자료 응답을 확인한다.
