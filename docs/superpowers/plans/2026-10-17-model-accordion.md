# 모델별 아코디언과 재시도 집계

사용자 요청: 비교표를 간소화하고 기권을 횟수로 표시한다. 모델 클릭 시 아코디언에 재시도·거부·타임아웃·에이전트·토큰 사용량과 실제 기록에 근거한 총평을 표시한다.

- 재시도는 원래 묶음의 첫 실행 이후 추가 시도 수다. original_group_id가 같은 분할 복구를 함께 집계한다.
- 아코디언 총평은 완료 상태·과목별 원점수 차이·복구 결과·공식/보정 점수 차이를 요약한다. 일반 능력을 추정하거나 새 모델을 호출하지 않는다.
- 기본 화면은 비교표만 보이며 문항별 기록은 명시적 버튼으로 연다. model 쿼리는 해당 아코디언을 열고, #model-records는 문항 기록을 연다.
- 시험 조건·측정 한계와 공통 실행 설명은 별도 접힌 영역에 둔다.
- 키보드 Enter로 접기·펴기, 반복 문항 이동, 390px 모바일 전체 너비를 검증한다.

검증: 테스트63개 통과. 정적 빌드 통과. 코드 리뷰에서 발견한 자동 스크롤 문제를 실제 브라우저에서 재현하고 명시적 이동 횟수로 수정했다. 원래 모바일 표의 숨김 열과 colspan이 충돌하는 문제는 4열 그리드로 해결했고 337px 표·상세 너비 일치를 확인했다. 완전/불완전 실행의 총평과 공유 링크를 확인했다.
