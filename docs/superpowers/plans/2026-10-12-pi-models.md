# Pi를 사용하는 네 모델 추가 평가

## 승인 범위

사용자는 DeepSeek V4.1 Flash, GLM 5.3 Flash, Qwen3.8-27B, Kimi K3에 대해 API 사용을 명시적으로 승인했다. 이 네 모델의 키는 `~/.zsh_secrets`에서 필요한 변수만 읽는다. 기존 Codex·Claude 결과와 구독 인증 보호는 유지한다. API 키·환경 변수 값·개인 계정 정보를 git, 결과 JSON, 웹에 넣지 않는다.

## 실행 조건

- Pi CLI 0.87.1을 사용한다. 묶음마다 빈 작업 디렉터리와 격리된 설정을 생성한다.
- 모델 ID와 공식 API 엔드포인트를 고정한다. 다른 모델·리전·공급자로 자동 대체하지 않는다.
- 공식 원본 PDF의 동일한 200 DPI 무손실 WebP와 기존 147문항·채점 키·기권 정책을 사용한다. Pi 자동 이미지 축소를 끈다.
- 도구·확장·스킬·문맥 파일·프롬프트 템플릿·자동 재시도·문맥 압축·캐시 예열을 끈다.
- SDK 구조화 출력 대신 동일한 답안 스키마의 JSON을 지시하고, 기존 검증기로 답안을 검사한다. 정답표와 다른 모델 답안은 입력에 넣지 않는다.
- high 추론을 요청한다. Qwen은 API에 해당 강도 옵션이 없으므로 thinking 활성화 조건을 별도로 기록한다.
- 묶음당 출력 상한 65,536토큰, 제한 900초, 동시 요청 2개, 누적 최대 3회다. 제출된 답과 기권은 잠근다. 일반 재시도 후 실행 오류가 남으면 최대 6문항의 안정된 분할 묶음으로 한 차례만 복구한다. 원래 조건·실패·사용량은 보존하고 출력·시간·요율 상한을 올리지 않는다.
- 모델별 누적 API 참고 비용 25 USD에 도달하면 새 요청을 멈춘다. 이 값은 서버 청구 상한이 아니며 요청 중 발생하는 비용을 보장하지 않는다.
- 계정·한도·모델 불일치·도구 호출 오류는 활성 요청을 취소하고 이후 묶음을 멈춘다.

## API 경로와 참고 비용

| 모델 | API 모델 ID | 공식 경로 | 키 변수 |
| --- | --- | --- | --- |
| DeepSeek V4.1 Flash | deepseek-flash | api.deepseek.com | DEEPSEEK_API_KEY |
| GLM 5.3 Flash | glm-5.3-flash | api.z.ai/api/paas/v4 | GLM_API_KEY |
| Qwen3.8-27B | qwen3.8-27b | dashscope-intl.aliyuncs.com/compatible-mode/v1 | QWEN_API_KEY |
| Kimi K3 | kimi-k3 | api.moonshot.ai/v1 | KIMI_API_KEY |

읽기 전용 모델 목록 요청으로 네 경로의 인증과 요청 모델 제공 여부를 확인했다. Qwen·Kimi 키는 국제 리전에서 유효하며 중국 리전에서는 인증되지 않았다. GLM Coding Plan 엔드포인트를 사용하지 않는다.

가격은 요청 시 사용량으로 계산한 API 참고 비용이다. 실측 청구서로 표시하지 않는다. DeepSeek은 피크 시간 요율을 보수적 참고값으로 사용하며 비피크 시간 단가는 50%다. Qwen은 국제 리전 요율이다. Kimi 캐시 쓰기는 기본 5분의 3 USD/100만 토큰을 사용한다. 총 입력은 비캐시 입력·캐시 읽기·캐시 쓰기를 합하며, 추론 토큰은 출력 토큰에 포함한다.

## 단계와 검증

- [x] 모델의 공식 ID·이미지 지원·리전·요율을 확인한다.
- [x] 비밀 값의 셸 실행·로그 출력을 피하는 키 로더와 환경 격리를 검사한다.
- [x] Pi 어댑터의 모델 고정·도구 차단·JSONL framing·사용량·취소·출력 검증 테스트를 통과한다.
- [x] DeepSeek의 작은 묶음으로 실제 이미지·답안·사용량을 확인하고 제출된 답을 보존한다.
- [x] 네 모델의 제한된 평가 실행을 종료하고 최종 상태를 기록한다. DeepSeek·Kimi는 147문항 완료, GLM·Qwen은 실행 오류로 불완전 종료했다.
- [x] 독립 채점 후 11모델 비교 JSON, 빌드, 데스크톱·모바일을 검증한다.
- [ ] GitHub Pages 배포와 공개 데이터·모델 선택·정렬을 확인한다.

## 최종 실행 상태와 검사 차단

DeepSeek는 108/147 정답·기권 3문항, Kimi는 138/147 정답·기권 1문항으로 완료했다. GLM은 91문항 제출·56문항 실행 오류, Qwen은 131문항 제출·16문항 실행 오류로 종료했다. 불완전 실행은 지표 순위에서 제외한다.

Qwen의 비공개·키 마스킹된 진단 기록에서 `DataInspectionFailed: Output data may contain inappropriate content.`를 확인했다. 기존 실행과 재시도 기록은 변경하지 않고 종료 후 설명을 추가했다. 앞으로 같은 묶음의 콘텐츠 검사 차단이 두 번 발생하면 해당 묶음 재시도를 종료한다. 현재 종료를 확정한 두 실행에는 추가 API 요청을 하지 않는다.
