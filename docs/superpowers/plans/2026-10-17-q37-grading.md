# 영어 37번 보정 채점 구현 계획

> **For agentic workers:** Use superpowers:executing-plans to implement this approved change.

**Goal:** 2026학년도 영어 37번의 ④·⑤를 벤치마크 정답으로 인정하고 ④를 정답*으로 표시한다.
**Architecture:** 공개 보고서 생성 후 보정 정책을 적용한다. 원본 정답표·run.json·공식 채점은 보존하고 official_summary/official_status로 함께 공개한다.
**Tech Stack:** Node.js, Next.js, TypeScript.
**Spec:** 사용자 승인: 공식 점수 병기, 모든 모델 동일 적용, 보정 근거와 정책 공개 후 배포.

## Global Constraints
- 모델 재호출 없음. 기존 2025 사용자 변경 보존.
- 2026 영어 37번에만 적용. 기권·실행 오류·미제출에는 정답을 부여하지 않는다.
- 비교표 정렬은 벤치마크 보정 점수 기준. 보정된 모델·정답률·영어 점수에 * 표시.

## Review Focus
- 다른 문항·학년도는 변경하지 않는다.
- ⑤ 제출 모델은 별표 없이 기존 점수를 유지한다.
- 불완전 실행은 보정 후에도 순위에서 제외한다.
- 사용량·비용·시간·원래 답안은 동일하다.
- 영어 37번 표의 공식 채점과 벤치마크 채점은 구분한다.
