# 2025학년도 저비용 실험 셋 수험

사용자 요구: 예전 모델 결과가 아닌 이번 실험 셋에서 API 요금이 없거나 매우 저렴한 모델 몇 개만 새로 평가하고 동일 리더보드로 표시한다.

선정: GPT-6 Luna, GPT-6.1 Sol, Claude Haiku5.5. Codex의 실제 ChatGPT 구독 인증·포함 사용량·구매 크레딧 없음 상태를 확인했다. Claude는 최신 추가 과금 OFF 확인에 필요한 UI 연결을 사용할 수 없어 실행을 보류하고 status.json으로 차단 사유만 공개한다. 유료 API로 대체하지 않는다.

구현:
- 공식2025 홀수형 문제지·정답표·듣기대본7개 파일의 공식 다운로드 해시 일치 확인.
- 정답·배점 전수 시각 대조, 문항 시작페이지 검증.147개 고유 문항,6개 응시 조합 각각100점.
- --year2025 실행, 연도별 입력·결과·잠금·캐시·ID 격리.2026 기존 경로와 프로토콜 보존.
- 별도 benchmark-comparison-2025.json과 동일 ComparisonDashboard 사용.2025에서는2026 영어37번 토론·보정 미적용.
- 코드 리뷰에서2025 다운로드가2026을 가리키는 문제를 찾아 연도별 파일로 수정.

실행 중 복구:
- Sol의 병렬 이미지 캐시 준비 오류와 Luna의 구독 상태 조회 일시 시간 초과를 보존했다.
- 완료된94문항을 재호출하지 않고 미제출 문항만 재개했다. 이전 중단 시도는 최종 사용량 미보고로 보존했다.
- 캐시는 임시 파일 완성 후 원자적으로 게시한다. 병렬 묶음 오류는 모든 형제 요청 정리를 기다린 뒤 잠금을 해제한다.
- 위 두 문제는 실패 재현 테스트 후 수정했으며 모델 설정·출력 상한·시간 제한·동시성·프롬프트·이미지 조건을 올리거나 바꾸지 않았다.

검증: 오프라인 테스트71개·정적 빌드·코드 리뷰 통과. 2025의 새 모델3개와2026의12개 분리, 토론 링크 조건, 다운로드 링크,390px 모바일, 아코디언, 중단 설명 표시, 브라우저 오류0 확인.

결과: Sol145/147 정답·기권0, Luna105/147 정답·기권5. 두 접근 가능한 모델 모두147문항 제출 완료. Claude는 성적을 만들지 않고 차단 상태로 남긴다. 기존2025 사용자 변경 파일6개는 보존한다.
