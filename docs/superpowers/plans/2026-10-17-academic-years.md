# 학년도 선택과 Argon 타임아웃 분류 수정

사용자 요구: 2025·2026학년도별 모델 비교, 2026 선택 시 영어37번 토론 연결, 2027은 선택 불가·준비 중, 상단에 2027학년도 시험일과 수험 예정 공지.

- 2025 기존 평가와 2026 원본 이미지 평가를 다른 화면·집계로 유지한다. 기존 2025 사용자 YAML 변경은 보존한다.
- year=2025/2026 공유 및 브라우저 이동을 지원한다. 2027 직접 쿼리도 선택하지 않는다.
- 2027학년도 시행일은 교육부 발표의 2026-11-19(목)이며 공식 출처를 연결한다.
- Argon은 거부 12문항이 아니라 언어·매체11문항 묶음 첫 요청의 타임아웃1회다. 재시도에 모두 제출됐다.
- 공개 원본 오류는 그대로 보존한다. 정확한 run/group/iteration/started_at/error와 일치하는 보존 진단 근거를 추가해 타임아웃1회로 집계한다.
- Pi의 Request timed out. 정규화가 향후에도 RequestTimeout 코드를 유지하도록 수정한다.

검증: 테스트62개, 정적 빌드, 코드 리뷰 통과. 2025/2026 전환과 뒤로/앞으로, 2025 과목 URL 유지, 2027 비활성, 390px 모바일, 2026의 토론 링크, Argon 거부0/타임아웃1 확인.

2025학년도 새 수험의 모델 범위는 사용자에게 질문했으며 답변 전 유료 API나 새 모델을 호출하지 않는다. 기존 결과 연결은 완료한다.
