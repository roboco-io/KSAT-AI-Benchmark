# Codex SDK 전 과목 평가와 정적 결과 대시보드 설계

## 목표와 범위

2026학년도 수능 홀수형 국어·영어·수학을 Codex SDK + GPT-6.1-Sol로 풀고 채점해 `https://roboco.io/KSAT-AI-Benchmark/`에 정적으로 공개한다. 모델이 모르는 문항은 기권할 수 있다. 정답률·기권률·전체 풀이 시간·토큰 비용 예상치를 표시한다.

국어는 공통 34문항과 선택과목 2종 각 11문항, 수학은 공통 22문항과 선택과목 3종 각 8문항, 영어는 45문항이다. 총 147개 고유 문항이며, 국어 선택과목별 45문항·100점 시험 2개, 수학 선택과목별 30문항·100점 시험 3개, 영어 45문항·100점 시험 1개로 집계한다.

매년 수능 전 전년도 문제를 최신 모델로 한 번 풀고, 수능 직후 새 문제를 같은 프로토콜로 평가한다. 정답 확정 후에는 모델 답을 바꾸지 않고 재채점한다. 사용자는 자료 확보·계획·구현·실제 풀이·배포를 명시적으로 요청했다.

## 원본과 검수

평가원 공식 게시판에서 문제지·정답표 6개와 영어 듣기 대본을 확보했다. 출처·다운로드 URL·SHA-256·페이지 수·정답 확정 근거는 `exams/pdf/2026/sources.json`에 저장한다. 정답표와 원문 페이지를 시각 검수해 `exams/datasets/2026-ksat.json`을 구성한다. 한국어 PDF의 본문을 텍스트 추출로 전사하지 않는다.

문제지의 앞 절반만 홀수형 입력으로 사용한다. 국어 공통은 PDF 1~12페이지, 화법과 작문 13~16, 언어와 매체 17~20이다. 수학 공통은 1~8, 확률과 통계 9~12, 미적분 13~16, 기하 17~20이다. 영어는 1~8페이지와 공식 듣기 대본이다.

페이지는 200 DPI PNG로 렌더링하고 전송 시 무손실 WebP로 인코딩한다. 크기와 디코딩된 RGB 픽셀이 동일함을 확인한다. 이미지 해시와 원본 PDF 해시를 기록한다. 원본 페이지의 본문·선택지·도표를 변형하지 않는다.

## 풀이와 Ralph 반복

`@openai/codex-sdk@0.162.1`의 `runStreamed`와 `local_image`를 사용한다. 모델은 `gpt-6.1-sol`, 추론 수준은 `high`다. 공급자·모델을 자동 대체하지 않는다. 공통·선택과목별 8개 묶음으로 공유 지문을 보존한다.

Ralph는 같은 기본 지시와 저장한 진행 기록을 반복 사용하는 SDK 루프다. Claude Stop 훅을 사용하지 않는다. 완료 답안과 기권은 잠그고 미제출·실행 오류만 재개한다. 묶음별 누적 시도 최대 3회, 요청당 900초, 동시 요청 2개, 확인된 사용량의 API 환산 예상 비용 상한 25 USD다. 이 상한은 사용량 없는 실패 호출의 비용까지 완전히 보장하지는 못한다.

Codex는 저장소 밖 임시 작업 공간에서 사용자 설정·세션 지속 없이 실행한다. 도구·검색·MCP·플러그인을 비활성화한다. 모델 입력에는 이미지와 문항 ID·번호·선택과목·유형만 넣는다. 정답·채점 결과·기존 답안을 넣지 않는다. 실제 도구 실행 이벤트가 발생하면 실패로 기록한다. 예비 호출은 공식 결과와 분리한다.

영어 듣기 1~17번은 모델의 음성 미지원 때문에 공식 대본 이미지로 풀이한다. 이 결과를 음성 청취 성능이라고 표시하지 않는다.

## 답안과 기권

```json
{"question_id":"2026-math-common-q01","decision":"abstained","answer":null,"explanation":"계산 결과를 충분히 검증하지 못했습니다.","abstain_reason":"uncertain"}
```

`answered`이면 객관식은 정수 1~5, 단답형은 정수 0~999이며 기권 사유는 `null`이다. `abstained`이면 답은 `null`, 사유는 `uncertain`, `unreadable`, `budget_exhausted`, `unsupported_input` 중 하나다. 확률 수치를 요구하거나 임의의 자신감 임계값을 사용하지 않는다.

문항 ID는 학년도·과목·선택과목·번호로 구성한다. 중복 ID·등록되지 않은 ID·범위 밖 답·기권과 숫자 답의 충돌은 거부한다. 파싱 실패를 설명에서 답을 추측해 복구하지 않는다. 짧은 최종 설명만 공개하며 비공개 내부 추론을 공개한 것으로 표시하지 않는다.

## 기록과 채점

`results/codex-2026/run.json`에 프로토콜·입력·프롬프트 해시·답안·시도·SDK 사용량·시간을 저장한다. 원본 이벤트는 `.runtime/events/`에 두고 git과 웹 공개에서 제외한다. 10초 heartbeat로 실행 시간을 보존하고, 재개 전에 입력·프롬프트·프로토콜을 비교한다. 일시적 연결 재개 안내와 최종 스트림 실패를 구분한다.

상태는 정답·오답·기권·실행 오류·미실행이다. 기권과 실패는 0점이며 전체 문항 분모를 유지한다. 시도 정답률은 정답/유효 답 제출 문항이며, 시도가 없으면 `null`이다. 전체 지표에서는 공통 문항을 중복 세지 않는다. 실행 오류나 미실행이 있으면 불완전 실행으로 표시한다.

전체 시간은 실제 경과 시간이다. 묶음 시간 합계는 병렬 처리로 경과 시간보다 클 수 있다. 문항별 시간·토큰·시험별 비용은 묶음 값을 균등 배분한 추정치다. SDK의 출력 토큰에 포함된 추론 토큰을 비용에 다시 더하지 않는다. 캐시 입력도 일반 입력과 중복 과금하지 않는다.

2026-10-12 공개 API 요율은 100만 토큰당 일반 입력 2 USD, 캐시 입력 0.1 USD, 캐시 쓰기 2.5 USD, 출력 10 USD다. 비용은 ChatGPT 구독의 실제 청구액이 아닌 API 환산 예상치다. 사용량을 반환하지 않은 실패 시도는 제외될 수 있으므로 사용량의 완전성과 하한 추정임을 표시한다.

## 정적 대시보드와 배포

`benchmark/export.mjs`가 검증한 실행 기록에서 `web/public/data/benchmark-v2.json`을 만든다. 공개 JSON에는 채점 답안·짧은 설명·통계·조건·출처만 포함한다. 인증 정보·내부 파일 경로·원본 이벤트는 제외한다.

Next.js는 JSON을 빌드 시 읽고 `output: export`로 HTML을 생성한다. 서버 API·데이터베이스·실시간 연결은 없다. 화면에는 학년도·모델·평가 시기·완료 상태, 정답률·기권률·시간·토큰·비용, 과목별 100점 성적표, 문항 필터·상세·기권 사유, 출처와 조건을 제공한다. 360px 모바일에서도 접근 가능하게 한다. 색상과 글자로 상태를 구분하고 키보드 포커스를 제공한다. 외부 폰트 다운로드 없이 빌드한다.

이전 방식은 `/archive.html`로 분리하고 새 결과와 합산하지 않는다. 기존 사용자 미커밋 파일 6개는 새 작업의 커밋에서 제외한다. GitHub Actions가 오프라인 테스트·데이터 내보내기·정적 빌드·Pages 배포를 수행한다. `basePath=/KSAT-AI-Benchmark`와 조직 도메인 `roboco.io`를 유지한다.

## 완료 기준과 한계

모든 147문항에 답 또는 자발적 기권을 받고 6개 시험을 100점 기준으로 채점한다. 오프라인 테스트, 무손실 이미지 검증, 실제 데이터 정적 빌드, 모바일·데스크톱 화면, 원격 커밋·배포 성공과 공개 URL의 실제 결과를 확인한다.

공개된 전년도 시험이 학습 데이터에 포함됐을 가능성을 배제하지 않는다. 원점수를 학생 표준점수·백분위·등급으로 바꾸지 않는다. 다음 학년도는 별도 자료·run ID를 사용하며 기존 실행을 덮어쓰지 않는다.
