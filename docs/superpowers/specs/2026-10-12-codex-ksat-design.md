# Codex SDK 전 과목 평가와 정적 결과 대시보드 설계

## 목표

2026학년도 수능 국어·영어·수학 홀수형의 모든 선택과목을 Codex SDK + `gpt-6.1-sol`로 풀고, 모르는 문항은 기권할 수 있게 한다. 결과 파일을 입력으로 학년도별 정적 웹사이트를 생성한다. 매년 수능 전에 전년도 시험을 평가하고 수능 직후 새 시험을 평가하는 운영을 지원한다.

사용자는 이후 범위를 **국어·영어·수학 전체의 실제 풀이·채점·배포**까지 확대했다. 대시보드는 **결과 데이터로 만드는 정적 웹사이트**다. 실행과 완료 기준의 최신 상세는 `../plans/2026-10-12-codex-sdk-annual-benchmark.md`를 따른다. 이 문서의 아래 수학 중심 설명은 첫 설계의 배경이며, 아래 최신 실행 조건이 충돌하는 항목보다 우선한다.

## 최신 실행 조건

- Codex SDK 0.162.1 + GPT-6.1-Sol, high 추론, 원본 200 DPI 이미지 입력.
- 문항별 요청 대신 공통·선택과목별 8개 묶음 요청으로 원본 지문을 보존한다.
- 국어 56·수학 46·영어 45, 총 147개 고유 문항이며 선택과목별 6개 시험을 각각 100점으로 채점한다.
- 영어 듣기는 공식 대본 이미지 입력이다. 음성 청취 평가로 표시하지 않는다.
- 로컬 계산을 포함한 외부 도구·검색·MCP·플러그인을 비활성화한다. SDK 도구 이벤트가 발생하면 실패로 기록한다.
- 같은 지시와 진행 파일을 사용하는 제한된 Ralph 반복으로 제출하지 못한 문항만 재개한다. 이미 제출한 답과 기권을 바꾸지 않는다.
- 정적 대시보드 배포 주소는 `https://roboco.io/KSAT-AI-Benchmark/`다. 비용은 반환된 사용량의 공개 API 환산 USD 추정치로 표시한다.
- 문항별 시간·사용량은 실제 묶음 값을 균등 배분한 추정치로 표시하며 전체 시간은 실제 경과 시간이다.
- 새 구현은 별도 SDK 평가 경로를 사용하고 기존 사용자 미커밋 파일은 변경·커밋하지 않는다.

## 확보한 원본과 입력

`exams/pdf/2026/`에 평가원 공식 게시판에서 국어·수학·영어 문제지와 정답표 6개를 확보했다. `sources.json`에 게시물·다운로드 URL, SHA-256, 크기, 페이지 수, 표본 시각 검수와 정답 확정 근거를 기록했다. 문제지에는 홀수·짝수형이 함께 있으므로 전체 파일을 그대로 첫 풀이 요청에 첨부하지 않는다.

수학 PDF는 40페이지다. 홀수형 공통은 PDF 1~8페이지, 미적분은 13~16페이지를 사용한다. 페이지 범위의 첫·끝 문항과 전체 30문항의 영역·배점은 구현 단계에서 전수 검수한다. 채점은 정답표 PDF 1페이지의 공통·미적분 열을 사용한다. 2025-11-25 평가원 발표는 정답 확정과 이의신청 대상 문항의 이상 없음을 확인한다.

원본 PDF를 200 DPI PNG로 렌더링하고 문항별 영역을 지정한다. 본문·선택지·도표를 전부 포함하며, 페이지를 넘으면 이미지 여러 개를 연결한다. 텍스트 전사본을 풀이 입력으로 사용하지 않는다. 각 영역은 페이지 번호·좌표·이미지 해시를 가진다. 이미지 입력은 Codex CLI가 지원하는 `--image`를 사용하기 위한 선택이며, API의 PDF 직접 입력 실험과 구분한다.

문항 ID는 `2026-math-odd-common-q01`과 `2026-math-odd-calculus-q23` 형식이다. 문제의 정답과 배점은 별도 `answer-key.json`에 둔다. 배점은 시험 스펙에 명시하며, 단답형은 정수 답을 사용한다.

## Codex 풀이

- 실행기: `codex exec`, 모델: `gpt-6.1-sol`, 추론 수준 기본안: `high`.
- 문항마다 새 세션을 만들고 순차 실행한다. 공식 실행은 전체 시험 1회다. 예비 실행은 별도 `phase=pilot`로 기록한다.
- Codex + 도구 사용의 성과를 측정한다. 이미지 읽기와 로컬 Python 계산을 허용한다. 웹 검색·외부 정답 접근·다른 모델 호출·기존 결과 참조는 허용하지 않는다. 순수 모델 API 평가와 같은 순위로 묶지 않는다.
- 모델을 다른 이름으로 자동 대체하지 않는다. CLI 버전·실제 모델 접근성은 첫 예비 실행에서 확인한다. 로컬에서 확인한 CLI 버전은 `0.162.1`이다.
- 한 문항 기본 제한은 300초다. 타임아웃은 실행 오류로 남긴다. 모델이 남은 예산 안에 해결할 수 없다고 판단하면 스스로 포기할 수 있다. 전체 실행의 사용량 상한은 예비 실행 후 설정하며 공식 실행은 상한 없이 시작하지 않는다.
- 로컬 계산은 한 세션 안에서 가능하지만, 제출 뒤 오답이나 포기라는 이유로 다시 풀이시키지 않는다. 인프라 실패는 재개 명령에서만 시도 이력을 보존하며 재실행한다.

### 격리

문항용 작업 공간에는 해당 문항의 이미지와 최소 지시만 넣는다. 저장소 루트, 정답표, 과거 결과, 사용자 홈을 풀이 프로세스에 노출하지 않는다. `--sandbox read-only`만으로 파일 접근 격리가 완성됐다고 가정하지 않는다.

풀이 프로세스는 읽기 범위가 제한된 실행 환경에서 실행한다. 로컬 계산용 임시 공간만 쓰게 하고, 모델 서비스 통신 이외의 네트워크 접근을 차단한다. 전용 Codex 설정에서 MCP·플러그인·검색과 전역 프로젝트 지시를 상속하지 않게 한다. 인증은 좁은 범위로 제공하며 인증 내용과 환경 변수는 결과에 기록하지 않는다. 이 격리와 계산 도구가 함께 작동하는지 확인하는 예비 실행이 공식 평가의 진입 조건이다. 실제 환경에서 강제할 수 없으면 공식 결과로 표시하지 않는다.

### 답안과 포기

```json
{
  "question_id": "2026-math-odd-common-q01",
  "decision": "abstained",
  "answer": null,
  "explanation": "계산 결과를 충분히 검증하지 못했습니다.",
  "abstain_reason": "uncertain"
}
```

`decision`은 `answered` 또는 `abstained`다. `answered`이면 객관식은 정수 1~5, 단답형은 정수 0~999를 받으며 `abstain_reason=null`이다. `abstained`이면 `answer=null`이고 사유는 `uncertain`, `unreadable`, `budget_exhausted` 중 하나다. 자신감 수치를 요구하거나 임의의 확률 임계값으로 답을 바꾸지 않는다. 포기 정책은 모든 문항에 같은 문구로 적용한다.

실행 오류·잘못된 형식·아직 실행하지 않은 문항은 모델의 포기와 다르다. 파싱 실패를 설명에서 답을 추측해 복구하지 않는다. 모델의 짧은 설명만 공개하고 비공개 내부 추론을 공개한 것으로 표시하지 않는다.

## 기록과 채점

실행 단위는 `runs/<run_id>/`다. `manifest.json`에 운영 연도, 시험 학년도, 사전·직후·예비 구분, 모델·CLI·추론 설정, 프롬프트·입력 해시, 도구 정책, 제한, 시각을 남긴다. 문항별 JSONL 이벤트와 최종 답안은 따로 저장한다. 정답·채점은 모델 실행이 끝난 뒤 별도 프로세스에서 합친다.

정답·오답·포기·형식 오류·실행 오류·미실행의 여섯 상태를 표시한다. 30문항 전체 분모를 유지하며 포기와 실패는 0점이다. 일부 실행을 100점 시험의 완료 결과로 표시하지 않는다. 점수는 100점 만점 원점수이며, 시도율은 유효 답 제출 문항/30, 시도 정답률은 정답 문항/유효 답 제출 문항이다. 시도가 0개이면 시도 정답률은 `null`로 표시한다. 모델의 포기를 완료로 취급하되 실행 오류가 남으면 실행은 불완전이다.

재개는 완료 답안·포기를 보존하고 미실행과 명시적으로 재시도하는 인프라 오류만 처리한다. 조건 해시가 다르면 새로운 실행을 만든다. 정답 변경 시 기존 답안을 재호출하지 않고 새 채점 버전을 생성한다. Codex 사용량에서 비용을 산정할 수 없는 인증 방식이면 비용은 `null`과 이유를 표시하며 API 가격을 실제 구독 청구액으로 표시하지 않는다.

## 정적 대시보드

Next.js의 기존 `output: 'export'`와 GitHub Pages를 유지한다. `scripts/export_benchmark.py`가 결과를 검증하고 `web/public/data/benchmark-v2.json`을 생성한다. 결과 JSON은 빌드 시 읽어 정적 HTML에 포함한다. 서버 API, 데이터베이스, 로그인, 실시간 WebSocket은 만들지 않는다. 결과 갱신은 데이터 내보내기·정적 빌드·재배포로 수행한다. 화면의 진행 상태는 빌드 시점의 기록이며 실시간으로 표현하지 않는다.

공개 산출물에는 문항 상태·답·짧은 설명·점수·기간·사용량 등 필요한 필드만 넣는다. 원본 이벤트 로그·인증 정보·내부 경로는 웹에 복사하지 않는다. 원본 시험지는 출처 링크를 기본으로 제공하고, 저장소에 확보했다는 이유만으로 PDF나 문항 이미지를 웹 공개 폴더에 자동 복제하지 않는다.

첫 화면은 **학년도별 성적표와 문항 답안표**다. 학년도, 평가 시기, 과목·선택과목, 실행을 선택한다. 기본값은 가장 최신의 공개된 공식 실행이다. 미선택 실행으로 URL을 열면 데이터 없음 상태와 선택 가능한 실행을 표시한다. 공유 URL에는 `run`과 `question`을 사용하고 반복 번호만으로 문항을 찾지 않는다.

```text
수능 AI 성적표                 평가 기록 다운로드
[2026학년도] [수능 전] [수학 · 미적분] [실행 선택]
Codex + GPT-6.1-Sol            확정 정답 / 실행 완료
원점수  /100   정답  /30   포기    시도율    풀이 시간
공통 1~22   □ □ □ □ ...       미적분 23~30   □ □ ...
[전체] [정답] [오답] [포기] [오류] [미실행]
문항 번호 | 제출 답 | 정답 | 상태 | 배점 | 시간
선택 문항: 설명 / 포기 사유 / 원본 출처 / 실행 조건
연례 비교: 같은 시험의 과거·현재 평가 / 같은 모델의 전후 시험
```

색상은 배경 `#F7FAFC`, 본문 `#142C44`, 정답 `#176B4D`, 오답 `#B53A46`, 포기 `#875900`, 미실행 `#65758B`를 사용한다. 포기와 미실행은 색상뿐 아니라 글자·기호로 구분한다. 한국어는 Noto Sans KR 계열, 숫자는 tabular-nums로 정렬하며 글꼴은 로컬 패키지·정적 자원으로 제공해 외부 폰트 서비스가 빌드를 막지 않게 한다. 좌측 정렬, 성적표 표와 답안표 중심, 불필요한 카드·애니메이션을 줄인다. 360px 모바일에서는 문항 상세를 표 아래로 이동한다. 키보드 선택·보이는 포커스·읽기 순서를 검증한다.

기존 901줄 `LeaderboardContent.tsx`는 과거 결과 화면으로 보존한다. 새 화면은 데이터 타입·집계·필터·문항표·문항 상세를 분리한다. 기존 결과는 `/legacy/`에서 과거 방식으로 표시하며 새 결과와 합산하지 않는다.

## 연례 운영과 범위

2026년 수능 전에는 이번 2026학년도 시험을 평가하고, 2026-11-19 수능 문제 공개 직후에는 같은 프로토콜로 2027학년도 시험을 평가한다. 직후 결과는 잠정 정답 기준, 최종 정답 확정 후에는 재채점한다. 모델 버전을 고정할 수 없는 경우 그 제약을 기록한다. 시험 난도와 학습 데이터 포함 가능성이 달라 전후 점수 차이를 능력 변화로 단정하지 않는다.

첫 구현에서 다중 공급자, 영어 듣기, 검색 기반 풀이, 사람의 수동 답 수정, 반복 풀이 투표, 예약 실행, 데이터베이스는 제외한다. 국어·영어 자료는 확보했지만 첫 실행에 포함하지 않는다.

## 완료 기준

1. 공식 출처·해시가 있는 수학 30문항과 100점 정답·배점 데이터가 원본 전수 검수를 통과한다.
2. Codex가 실제 `gpt-6.1-sol`로 이미지 문항을 받고 제출하거나 포기한다. 강제 격리·제한·로그가 검증된다.
3. 정답·오답·포기·형식 오류·실행 오류·미실행을 구분해 정확히 집계한다.
4. 중단·재개·정답 재채점에서 기존 답안이 바뀌거나 중복되지 않는다.
5. 결과 파일만으로 정적 빌드가 성공한다. 360px·1440px 화면, 딥링크, 데이터 없음, 포기 상세를 확인한다.
6. 실제 풀이를 실행하지 않은 데이터는 예시 또는 테스트임을 명시하고 실험 결과로 공개하지 않는다.
