# 수능 수험

사용자가 지정한 모델만 현재 프로젝트의 공식 수능 데이터로 평가하고 결과를 대시보드에 등록한다. 설명이나 계획에 그치지 않고, 접근 가능한 모델의 실제 풀이·독립 채점·정적 배포를 완료한다.

`scripts/run_exam.py`는 자신의 실제 경로에서 이 스킬을 관리하는 `KSAT-AI-Benchmark` 저장소 루트를 찾는다. 다른 프로젝트에서 호출하면 이 저장소로 이동한다. 현재 데이터셋은 2026학년도 국어·수학·영어 147개 고유 문항이다. 학년도·회차를 지정하면 기존 실행과 다른 경로를 사용하고 해당 공식 데이터셋을 먼저 검증한다.

## 모델별 에이전트

| 공급자 | 필수 실행 경로 | 인증 기본값 |
| --- | --- | --- |
| OpenAI | Codex SDK | 기존 ChatGPT 구독 로그인 |
| Anthropic | Claude Code의 Claude Agent SDK | 기존 Claude 개인 구독 OAuth |
| Google | Antigravity CLI (`agy`) | 기존 Google 계정 로그인 |
| 그 외 | Pi agent | 해당 모델에 승인된 API 또는 구독 경로 |

다른 에이전트로 자동 대체하지 않는다. 요청 모델의 공식 ID·이미지 지원·요율과 사용자 계정의 해당 접근 권한을 확인한다. [공급자별 조건](references/providers.md)은 해당 공급자 부분만 읽는다.

## 실행과 등록

1. 지정한 모델을 `benchmark/models.mjs`와 `benchmark/profiles/*.json`에서 찾는다. 이름이 모호하면 공식 모델 목록을 확인하고, 결과에 영향을 주는 모호성만 질문한다. 키 값은 채팅으로 요청하지 않는다.
2. 없는 모델은 공식 문서와 읽기 전용 모델 목록으로 메타데이터를 확인해 프로필 JSON을 만든다. `scripts/run_exam.py --register <profile.json>`으로 등록한다. 프로필은 모델 ID·공급자·에이전트·입력 지원·요율·근거·경로만 포함하며 키 값은 포함하지 않는다.
3. `scripts/run_exam.py --model <정확한 ID> --dry-run`으로 선택된 경로와 진행 상태를 확인한다. 현재 회차의 완료된 실행은 재호출하지 않는다. 새 시험 회차 요청은 답안을 덮어쓰지 않고 새 실행을 만든다.
4. 접근 조건이 확인되면 `scripts/run_exam.py --model <ID>`를 실행한다. 여러 모델은 `--model`을 반복한다. Pi의 유료 API가 해당 요청 범위에서 승인된 경우 `--authorize-api`를 넣는다. 모델명을 받아 시험·등록하라는 지시는 해당 모델의 통상적인 실행과 기존 Pages 배포를 포함한다. 별도 구독 구매·충전·유료 대체는 포함하지 않는다.
5. 실행기는 제출된 답과 기권을 고정하고 미제출·실행 오류만 제한 내에서 재개한다. 묶음별 오류·토큰·시간도 보존한다. 같은 모델의 진행 중 실행을 중복 호출하지 않는다. 일반 재시도가 끝난 뒤에도 출력·시간·전송 오류가 남으면 미제출 문항에만 최대 6문항의 안정된 묶음으로 한 차례 복구한다. 이전 조건과 실패를 보존하며 가격·출력 상한·시간 제한은 올리지 않는다. 요청이 계속 실행 중이면 모델·로그 경로·프로세스 식별자를 유지하며 완료까지 추적한다.
6. 제공자 콘텐츠 검사 차단이 같은 묶음에서 두 번 발생하면 해당 묶음의 재시도를 종료한다. 입력·출력 범위를 확인할 수 있으면 따로 기록한다. 종료를 확정한 오류 실행은 자동 복구하지 않는다. 각 접근 가능한 모델의 실제 답안을 독립 채점하고 `benchmark/export.mjs`로 비교 JSON을 만든다. 대기·차단·실행 오류를 기권으로 바꾸거나 성적을 만들어 넣지 않는다. 미완료 모델은 순위에서 제외한다.
7. 오프라인 테스트·정적 빌드·새 모델 선택·정렬·모바일·브라우저 오류를 검증한다. 실행기는 해당 결과·프로필·JSON만 커밋하고 모든 설정된 원격에 푸시한다. 사용자 기존 변경은 보존한다.
8. Pages 배포 성공과 공개 JSON·표시값 일치를 확인한다. 기본 공개 주소는 `https://roboco.io/KSAT-AI-Benchmark/`다. 최종 답변은 결과, 기권, 시간·토큰·참고 비용과 URL, 필요한 차단 사유를 짧게 보고한다.

## 수학 풀이의 LaTeX 표기

- 새 시험의 수학 `explanation`에는 수식을 LaTeX로 작성한다. 인라인은 `$...$`, 독립 수식은 `$$...$$`를 쓰며 한국어 설명은 구분자 밖에 둔다. 분수·근호·지수·첨자·합·적분은 `\frac`, `\sqrt`, `^{...}`, `_{...}`, `\sum`, `\int`로 적고 JSON 역슬래시를 이스케이프한다. `answer`는 정수 또는 null을 유지한다.
- 새 실행은 LaTeX 지시가 포함된 프롬프트 버전을 기록한다. 기존 실행을 재개할 때는 잠긴 프롬프트·해시를 그대로 사용하고, 표기 변경을 이유로 모델을 재호출하거나 완료 답안을 수정하지 않는다.
- 기존 풀이의 일반 텍스트 수식은 화면 표시 단계에서 의미가 명확한 표기만 LaTeX로 변환한다. 원본 설명·답·채점·토큰·비용은 결과 JSON과 Git에 보존하고, 화면에는 정리된 풀이만 표시한다. 모호하거나 잘못된 표기는 원문으로 표시하며 수학적 오류를 고치거나 새 풀이를 만들지 않는다.

## 시험의 불변 조건

- 공식 원본 PDF의 200 DPI 무손실 이미지와 검증된 문항 ID를 사용한다. 한국어 PDF를 텍스트 파싱해 시험 입력으로 바꾸지 않는다.
- 정답표·다른 모델 답안·저장소 파일·검색·도구를 모델에 제공하지 않는다. SDK 출력 형식 캐리어만 허용한다.
- 확신 부족·입력 판독 불가에서는 기권할 수 있다. 기권과 실행 오류를 구분한다.
- 전체 집계에서 공통 문항을 한 번만 센다. 선택과목 성적은 국어·수학·영어로 묶어 표시한다.
- 영어 듣기 1~17번은 공식 대본 이미지 조건이다. 음성 청취 성능으로 표현하지 않는다.
- 모델·이미지·프롬프트·실행 설정의 해시를 잠근다. 답안 제출 후 설정을 바꾸면 변경 전 조건과 영향받은 시도를 명시적으로 보존하거나 새 실행으로 분리한다.
- 모델별 토크나이저와 추론 강도가 동일하다고 주장하지 않는다. 입력·캐시·출력·추론의 포함 관계를 SDK 계약으로 확인한다.
- 비용은 API 환산 참고값이다. 심볼 설명은 “실측 청구액이 아님”이다. 실측 청구서와 혼동하지 않는다.

## 인증·차단

Codex·Claude에는 API 키를 전달하지 않는다. Codex 포함 사용량과 유료 크레딧 부재, Claude Usage credits OFF의 신선한 계정별 증명을 확인한다. 이전에 확인한 오래된 상태로 과금 차단을 가정하지 않는다.

Pi는 승인된 모델의 키 하나만 `~/.zsh_secrets`에서 읽는다. 파일을 셸로 실행하지 않는다. 자식 프로세스 설정은 격리하고 자동 재시도·캐시 예열·문맥 압축·이미지 축소를 끈다. 현재 기본 상한은 묶음당 최대 3회·15분·동시 2요청, 모델별 참고 비용 25 USD이며 실제 청구 상한을 보장하지 않는다.

Antigravity는 공식 네이티브 이미지 입력과 도구 비활성화를 확인한 경우에만 실행한다. 현재 `agy` 1.3.2의 headless 입력은 텍스트 블록만 지원하므로 이미지 시험 실행을 차단한다. 사용자가 Google 모델을 요청하면 당시 CLI와 공식 문서를 다시 확인한다. 새 버전에서 필요한 계약이 검증되면 해당 어댑터를 구현·검증한 뒤 실행한다. 이미지 시험을 텍스트 시험으로 바꾸거나 Gemini CLI·SDK로 대체하지 않는다.

접근 권한·키·구독 한도·네이티브 이미지 입력을 확보할 수 없으면 해당 모델만 사유와 함께 차단 상태로 기록한다. 계정 충전이나 구매를 하지 않는다. 필요한 정보는 비밀 값 없이 질문하고, 다른 실행 가능한 모델은 계속 진행한다.
